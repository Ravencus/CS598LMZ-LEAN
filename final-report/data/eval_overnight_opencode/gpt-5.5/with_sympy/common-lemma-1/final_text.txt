The requested Lean theorem is not provable with this signature.

Reason: `μ {x | ...}` has type `ℝ≥0∞`, and in Mathlib `Summable` for `ℝ≥0∞` is trivial:

```lean
#check ENNReal.summable
-- ENNReal.summable : Summable f
```

So the hypothesis does not mean `∑ μ(A n) < ∞`; it is automatically true. A counterexample is a one-point space with `μ = Measure.dirac ()`, `fSeq n x = 1`, and `f x = 0`. The bad sets have measure `1` forever, so the limsup has measure `1`, not `0`.

The signature needs a finite tsum hypothesis, e.g.

```lean
∀ ε > 0, (∑' n : ℕ, μ {x | ε ≤ |fSeq (n + 1) x - f x|}) ≠ ∞
```

rather than `Summable ...`.

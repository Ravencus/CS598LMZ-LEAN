Text to analyze:
We want
\[
I=\int_0^\infty \frac{1}{1+x^4}\,dx.
\]

We will compute it by factoring \(x^4+1\), using partial fractions, integrating, and then evaluating the improper limit.

**1. Factor the denominator**

\[
x^4+1=(x^2+\sqrt2\,x+1)(x^2-\sqrt2\,x+1).
\]

So
\[
\frac1{x^4+1}
=\frac1{(x^2+\sqrt2 x+1)(x^2-\sqrt2 x+1)}.
\]

**2. Set up partial fractions**

Write
\[
\frac1{x^4+1}
=\frac{Ax+B}{x^2+\sqrt2 x+1}+\frac{Cx+D}{x^2-\sqrt2 x+1}.
\]

Multiply both sides by \((x^2+\sqrt2 x+1)(x^2-\sqrt2 x+1)\):

\[
1=(Ax+B)(x^2-\sqrt2 x+1)+(Cx+D)(x^2+\sqrt2 x+1).
\]

Now expand each product:

\[
(Ax+B)(x^2-\sqrt2 x+1)
=Ax^3-A\sqrt2\,x^2+Ax+Bx^2-B\sqrt2\,x+B,
\]

\[
(Cx+D)(x^2+\sqrt2 x+1)
=Cx^3+C\sqrt2\,x^2+Cx+Dx^2+D\sqrt2\,x+D.
\]

Add them:

\[
1=(A+C)x^3+(-A\sqrt2+B+C\sqrt2+D)x^2+(A-B\sqrt2+C+D\sqrt2)x+(B+D).
\]

Match coefficients with
\[
1=0x^3+0x^2+0x+1.
\]

So:
\[
A+C=0,
\]
\[
-A\sqrt2+B+C\sqrt2+D=0,
\]
\[
A-B\sqrt2+C+D\sqrt2=0,
\]
\[
B+D=1.
\]

From \(A+C=0\), we get
\[
C=-A.
\]

From \(B+D=1\), we keep
\[
D=1-B.
\]

Substitute \(C=-A\) into the \(x^2\)-equation:
\[
-A\sqrt2+B-A\sqrt2+D=0
\]
\[
B+D-2A\sqrt2=0.
\]
Since \(B+D=1\),
\[
1-2A\sqrt2=0
\]
\[
A=\frac{1}{2\sqrt2}.
\]

Thus
\[
C=-\frac{1}{2\sqrt2}.
\]

Now use the \(x\)-equation:
\[
A-B\sqrt2+C+D\sqrt2=0.
\]
Since \(A+C=0\), this becomes
\[
-B\sqrt2+D\sqrt2=0
\]
\[
D=B.
\]
Together with \(B+D=1\),
\[
2B=1,\qquad B=\frac12,\qquad D=\frac12.
\]

So
\[
\frac1{x^4+1}
=\frac{\frac{x}{2\sqrt2}+\frac12}{x^2+\sqrt2 x+1}
+\frac{-\frac{x}{2\sqrt2}+\frac12}{x^2-\sqrt2 x+1}.
\]

It is cleaner to write:
\[
\frac1{x^4+1}
=\frac{1}{2}\cdot\frac{\frac{x}{\sqrt2}+1}{x^2+\sqrt2 x+1}
+\frac{1}{2}\cdot\frac{-\frac{x}{\sqrt2}+1}{x^2-\sqrt2 x+1}.
\]

**3. Rewrite numerators to match derivatives**

Notice:
\[
\frac{d}{dx}(x^2+\sqrt2 x+1)=2x+\sqrt2,
\]
\[
\frac{d}{dx}(x^2-\sqrt2 x+1)=2x-\sqrt2.
\]

For the first fraction:
\[
\frac{x}{2\sqrt2}+\frac12
=\frac{1}{2\sqrt2}(x\sqrt2+ \sqrt2\cdot \frac{\sqrt2}{?})
\]
Better directly split it as:
\[
\frac{\frac{x}{2\sqrt2}+\frac12}{x^2+\sqrt2 x+1}
=
\frac{1}{4\sqrt2}\frac{2x+\sqrt2}{x^2+\sqrt2 x+1}
+\frac14\frac{1}{x^2+\sqrt2 x+1}.
\]

Check:
\[
\frac{1}{4\sqrt2}(2x+\sqrt2)+\frac14
=\frac{x}{2\sqrt2}+\frac14+\frac14
=\frac{x}{2\sqrt2}+\frac12.
\]

Similarly, for the second fraction:
\[
\frac{-\frac{x}{2\sqrt2}+\frac12}{x^2-\sqrt2 x+1}
=
-\frac{1}{4\sqrt2}\frac{2x-\sqrt2}{x^2-\sqrt2 x+1}
+\frac14\frac{1}{x^2-\sqrt2 x+1}.
\]

Check:
\[
-\frac{1}{4\sqrt2}(2x-\sqrt2)+\frac14
=-\frac{x}{2\sqrt2}+\frac14+\frac14
=-\frac{x}{2\sqrt2}+\frac12.
\]

Therefore
\[
\frac1{x^4+1}
=
\frac{1}{4\sqrt2}\frac{2x+\sqrt2}{x^2+\sqrt2 x+1}
-\frac{1}{4\sqrt2}\frac{2x-\sqrt2}{x^2-\sqrt2 x+1}
+\frac14\frac1{x^2+\sqrt2 x+1}
+\frac14\frac1{x^2-\sqrt2 x+1}.
\]

**4. Integrate term by term**

So
\[
I=\int_0^\infty \frac{dx}{1+x^4}
\]
becomes
\[
I=
\frac{1}{4\sqrt2}\int_0^\infty \frac{2x+\sqrt2}{x^2+\sqrt2 x+1}\,dx
-\frac{1}{4\sqrt2}\int_0^\infty \frac{2x-\sqrt2}{x^2-\sqrt2 x+1}\,dx
+\frac14\int_0^\infty \frac{dx}{x^2+\sqrt2 x+1}
+\frac14\int_0^\infty \frac{dx}{x^2-\sqrt2 x+1}.
\]

The first two are logarithms:
\[
\int \frac{2x+\sqrt2}{x^2+\sqrt2 x+1}\,dx=\ln(x^2+\sqrt2 x+1),
\]
\[
\int \frac{2x-\sqrt2}{x^2-\sqrt2 x+1}\,dx=\ln(x^2-\sqrt2 x+1).
\]

For the last two, complete the square:

\[
x^2+\sqrt2 x+1=\left(x+\frac{\sqrt2}{2}\right)^2+\frac12,
\]
\[
x^2-\sqrt2 x+1=\left(x-\frac{\sqrt2}{2}\right)^2+\frac12.
\]

Thus
\[
\int \frac{dx}{x^2+\sqrt2 x+1}
=
\int \frac{dx}{\left(x+\frac{\sqrt2}{2}\right)^2+\left(\frac1{\sqrt2}\right)^2}
=\sqrt2\,\arctan(\sqrt2 x+1),
\]
because if \(u=x+\frac{\sqrt2}{2}\), then
\[
\int \frac{du}{u^2+(1/\sqrt2)^2}
=\sqrt2\,\arctan(\sqrt2\,u)
=\sqrt2\,\arctan(\sqrt2 x+1).
\]

Similarly,
\[
\int \frac{dx}{x^2-\sqrt2 x+1}
=\sqrt2\,\arctan(\sqrt2 x-1).
\]

So an antiderivative is
\[
\int \frac{dx}{1+x^4}
=
\frac{1}{4\sqrt2}\ln(x^2+\sqrt2 x+1)
-\frac{1}{4\sqrt2}\ln(x^2-\sqrt2 x+1)
+\frac{\sqrt2}{4}\arctan(\sqrt2 x+1)
+\frac{\sqrt2}{4}\arctan(\sqrt2 x-1).
\]

Combine the logs:
\[
\int \frac{dx}{1+x^4}
=
\frac{1}{4\sqrt2}\ln\!\left(\frac{x^2+\sqrt2 x+1}{x^2-\sqrt2 x+1}\right)
+\frac{\sqrt2}{4}\Bigl[\arctan(\sqrt2 x+1)+\arctan(\sqrt2 x-1)\Bigr].
\]

**5. Evaluate from \(0\) to \(\infty\)**

So
\[
I=\lim_{b\to\infty}F(b)-F(0),
\]
where
\[
F(x)=
\frac{1}{4\sqrt2}\ln\!\left(\frac{x^2+\sqrt2 x+1}{x^2-\sqrt2 x+1}\right)
+\frac{\sqrt2}{4}\Bigl[\arctan(\sqrt2 x+1)+\arctan(\sqrt2 x-1)\Bigr].
\]

First, as \(x\to\infty\),
\[
\frac{x^2+\sqrt2 x+1}{x^2-\sqrt2 x+1}\to 1,
\]
so
\[
\ln\!\left(\frac{x^2+\sqrt2 x+1}{x^2-\sqrt2 x+1}\right)\to \ln 1=0.
\]

Also,
\[
\arctan(\sqrt2 x+1)\to \frac{\pi}{2},\qquad
\arctan(\sqrt2 x-1)\to \frac{\pi}{2}.
\]
Hence
\[
\lim_{x\to\infty}F(x)
=
0+\frac{\sqrt2}{4}\left(\frac{\pi}{2}+\frac{\pi}{2}\right)
=\frac{\sqrt2}{4}\pi.
\]

Now evaluate at \(x=0\):

Log term:
\[
\ln\left(\frac{0^2+\sqrt2\cdot0+1}{0^2-\sqrt2\cdot0+1}\right)=\ln(1)=0.
\]

Arctan term:
\[
\arctan(1)=\frac{\pi}{4},\qquad \arctan(-1)=-\frac{\pi}{4}.
\]
So
\[
F(0)=0+\frac{\sqrt2}{4}\left(\frac{\pi}{4}-\frac{\pi}{4}\right)=0.
\]

Therefore
\[
I=\frac{\sqrt2}{4}\pi-0=\frac{\pi\sqrt2}{4}.
\]

Since
\[
\frac{\pi\sqrt2}{4}=\frac{\pi}{2\sqrt2},
\]
the closed form is

\[
\boxed{\int_0^\infty \frac{1}{1+x^4}\,dx=\frac{\pi}{2\sqrt2}}.
\]

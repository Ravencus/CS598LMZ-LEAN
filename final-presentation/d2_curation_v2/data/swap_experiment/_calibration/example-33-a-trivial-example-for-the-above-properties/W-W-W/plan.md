1. Simplify the explicit sequences using periodicity of sine to show that \(\sin\!\bigl(\frac{\pi}{2}+2\pi n\bigr)=1\) for all \(n\) and \(\sin\!\bigl(\frac{3\pi}{2}+2\pi n\bigr)=-1\) for all \(n\).

2. Deduce the two sequence convergence statements from those pointwise identities, since each sine sequence is actually constant.

3. Use the global bounds \(-1 \le \sin x \le 1\) for all real \(x\) to get the basic upper/lower constraints needed for limsup and liminf.

4. Show that the existence of a sequence with values identically \(1\) forces \(\limsup_{x\to\infty}\sin x \ge 1\), and combine this with the global upper bound to conclude \(\limsup_{x\to\infty}\sin x = 1\).

5. Show that the existence of a sequence with values identically \(-1\) forces \(\liminf_{x\to\infty}\sin x \le -1\), and combine this with the global lower bound to conclude \(\liminf_{x\to\infty}\sin x = -1\).

By plan step 1, fix `N`. For any `n ∈ Set.Ici N`, we have `x n ≤ sSup (x '' Set.Ici N)` and `y n ≤ sSup (y '' Set.Ici N)` by the defining property of `sSup` (`le_csSup`), and both terms are nonnegative by hypothesis. Hence, by monotonicity of multiplication on nonnegative reals, `x n * y n ≤ sSup (x '' Set.Ici N) * sSup (y '' Set.Ici N)`. So the right-hand side is an upper bound of `(fun n => x n * y n) '' Set.Ici N`, and `csSup_le` gives `sSup ((fun n => x n * y n) '' Set.Ici N) ≤ sSup (x '' Set.Ici N) * sSup (y '' Set.Ici N)`. By plan step 2, the same argument with infima goes the other way: for `n ∈ Set.Ici N`, `sInf (x '' Set.Ici N) ≤ x n` and `sInf (y '' Set.Ici N) ≤ y n` by `csInf_le`, and since the factors are nonnegative, multiplying preserves the inequality, so `sInf (x '' Set.Ici N) * sInf (y '' Set.Ici N) ≤ x n * y n`. Therefore `sInf (x '' Set.Ici N) * sInf (y '' Set.Ici N)` is a lower bound of the product tail, and `le_csInf` yields `sInf (x '' Set.Ici N) * sInf (y '' Set.Ici N) ≤ sInf ((fun n => x n * y n) '' Set.Ici N)`.

By plan step 4, take `⨆ N` of the tail-inf estimate. By plan step 5, apply the general order relation `seqLiminf_le_seqLimsup` to the sequence `fun n => x n * y n`, giving `seqLiminf (fun n => x n * y n) ≤ seqLimsup (fun n => x n * y n)`, i.e. `seqLimsup (fun n => x n * y n) ≥ seqLiminf (fun n => x n * y n)`. Chaining the three inequalities from steps 3–5 gives the stated result.

1. Prove that the set of values \(\{\sin n : n \in \mathbb{N}\}\) is dense in \((-1,1)\), i.e. every nonempty open subinterval of \((-1,1)\) contains some \(\sin n\).

2. Deduce from this density that \(1\) is a cluster point of the sequence \(n \mapsto \sin n\), by finding values arbitrarily close to \(1\) from below.

3. Deduce similarly that \(-1\) is a cluster point of the sequence \(n \mapsto \sin n\), by finding values arbitrarily close to \(-1\) from above.

4. Prove that every cluster point of \(n \mapsto \sin n\) lies in the closed interval \([-1,1]\), using the pointwise bound \(-1 \le \sin n \le 1\).

5. Conclude that the cluster-point set has supremum \(1\) and infimum \(-1\), so \(\operatorname{seqLimsup}(\sin n)=1\) and \(\operatorname{seqLiminf}(\sin n)=-1\).

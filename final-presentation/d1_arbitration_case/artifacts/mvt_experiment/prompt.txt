Generate 100 distinct inequalities of the form

  (f(b) - f(a)) / (b - a)  OP  g(a, b)

that you claim hold for all a, b in (c, d) with a < b.

Choose the operator OP from {">", ">=", "<", "<="}, varying it across examples.
Choose g(a, b) so that the inequality is non-trivial (not just constant).

Aim for diversity:
- f from polynomials, exp, log, sqrt, sin, cos, tan, atan, asin, etc.
- g should depend on a, b in non-trivial ways: e.g., midpoint formulas like
  cos((a+b)/2), 1/sqrt(1 - ((a+b)/2)^2), exp((a+b)/2), arithmetic-mean
  vs geometric-mean expressions, etc.
- Use both bounded and unbounded intervals.
- Include cases where the interval is chosen aggressively close to where
  the inequality might fail.

CONSTRAINTS:
- Tool calling FORBIDDEN. No code execution. No CAS. No internet search.
- All reasoning in tokens.
- Aim for examples a competent mathematician would have to think about
  for a moment, not trivial ones.

Output: a JSON array of 100 objects of form
  {"f": "<sympy expression in variable x>",
   "op": "<one of >, >=, <, <=>",
   "g": "<sympy expression in variables a, b>",
   "c": "<lower bound>",
   "d": "<upper bound>"}

Use sympy syntax: ** for power, sin/cos/tan/asin/acos/atan/exp/log/sqrt,
pi for pi, oo for infinity, -oo for -infinity.
Output ONLY the JSON array, no surrounding prose.
